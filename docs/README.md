## 目录约定

- 仓库根 `README.md`：项目门面与入口，保持精简，细节一律链接到 `docs/`。
- `docs/tutorials/`：实操教程，按主题编号（01、02…），一篇一个可独立完成的动手主题，统一「目标 → 前置条件 → 操作步骤 → 验证方法 → 常见问题」结构。
- `docs/case-study/`：贯穿案例的核算底稿与配套分析。
- `docs/snapshots.md`：版本快照（tag）的对照说明，随仓库演进更新。
- 模块专属的实现说明写在对应模块的源码注释中，不在 `docs/` 重复维护同一篇长文档。
